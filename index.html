PROJECT OVERVIEW

This project is a small FPGA-based hardware accelerator designed using Verilog HDL. The goal of the design is to process incoming numerical data with low latency and deterministic timing using hardware logic instead of software execution.

The module receives a 4-bit input digit and performs real-time processing to:

  • Track the maximum digit received
  • Store previous input values
  • Perform arithmetic operations
  • Generate an output result
  • Signal when computation is complete

The project was developed as part of an FPGA-focused hackathon to explore high-speed hardware computation and digital system design.

MOTIVATION

Traditional processors execute instructions sequentially, which can introduce delays in time-sensitive systems. FPGA-based systems allow computations to be performed directly in hardware, enabling:

Faster Execution 100%
Parallel Processing 95%
Predictable Latency 98%
Real-Time Performance 100%

These characteristics are especially useful in areas such as:

  • High-frequency trading
  • Robotics
  • Signal processing
  • Embedded systems
  • Hardware acceleration

DESIGN ARCHITECTURE

The design uses a modular RTL-based architecture with:

1. Finite State Machine (FSM)

The FSM controls the flow of computation through different stages:

IDLE
→
LOAD
→
COMPUTE
→
DONE
State Function
IDLE Waits for start signal
LOAD Reads input digit
COMPUTE Performs arithmetic operation
DONE Signals computation completion

2. Datapath

The datapath handles:

  • Comparison logic
  • Arithmetic operations
  • Register storage

The module continuously tracks the largest digit received and computes the result using hardware arithmetic.

3. Pipelined Computation

The computation is divided into stages to improve timing performance and hardware organization.

Pipeline stages include:

Input Register
→
Comparator
→
Multiplier
→
Adder
→
Output Register

This structure improves scalability and makes the design easier to optimize for higher clock frequencies.

COMPUTATION

The module computes:

result = (max_digit × 10) + previous_digit

Where:

  • max_digit is the largest digit received so far
  • previous_digit is the most recent stored input
